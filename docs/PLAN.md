# Legion × DeepSeek Harness

批准目标：把军团接入 DeepSeek Harness 的插件生态，完成可安装版本、真实联调与市场投稿。

## 分工

DSH 保留自己的会话、主循环、权限和界面。插件只连接一个由用户配置并授权的 Legion 服务。军团继续负责接到的任务；插件不再组织第二个军团、不评价作品好坏。

公开范围仅限此独立仓库中新写的连接器、测试、文档与投稿资料。Legion 服务不随包分发；不包含任何公司的源码、凭据或用户对话。现有主仓库不修改。

## 关键技术选择

- 使用官方 `defineTool` 和 `commands.register`，不修改 DSH 内核。
- 预构建 ESM JavaScript，不在安装时执行构建脚本。
- 官方固定 Git 手动安装、自托管 Git index、1024Store 目录是三层；npm 登录并非 Git 路线或目录投稿前置，但当前 1024Store 正式一键安装是 npm-only。
- 只保存在本机恢复任务所需的最少索引；不复制整段 DSH 历史或目录。
- 任务状态以服务返回为准；网络失败保留“未能确认”，不推断成功或失败。
- 本地验证与公开材料分开：私有证据、日志、会话与运行目录不进入公开 Git 或安装包，文档不引用其路径。
- 原生工具与命令共用连接链；配置只能由用户提供，个人令牌仅从环境读取。后端另需授权，MIT 仅覆盖连接器。
- 市场审核由维护者决定；“可安装”“已投稿”“已收录”是三个不同事实。

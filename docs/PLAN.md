最新集成验证运行于 **2026-10-28 04:25:05–04:25:09 UTC，即同日 12:25:05–12:25:09 Asia/Shanghai**。Node **v24.20.0** 下 `npm run check`、`npm test` 均退出 0，**357/357 通过**，失败、取消、跳过均为 0，源码前后哈希一致。30 份代码、测试和清单文件仍与该记录匹配；复用同字节证据，不冒充重跑全套。运行目标仍是官方 npm **`@deepseek-ai/dsh@0.2.1-rc.2`**，没有升级依赖。验证范围是隔离测试和官方 Runtime，**不等于真实 Host 或端到端通过；尚未公开发布。**

## 目标与范围

普通用户先接入开源能力：找现成工具／插件、按固定提交读真实源码、由作者完成适配，再包装为一包内可分别启停的原生插件。`legion_discover`、`legion_source`、`legion_bundle` 不要求先配 Legion token。可选军团协作才需要个人服务及授权，后端不随包分发。

DSH 保留对话、主循环、工具选择和权限；安装／开关交给官方 `plugin_manager`。连接器不一键转换任意库、不评判作品质量、不自动执行远端指令，也不在本机执行后自动发消息。公开范围只含此独立仓库的合法新写代码、依赖声明和文档，不含公司／后端源码、凭据、私有现场或用户产物；适配项目保留原许可。

## 已实现：源码事实，不等于原生验收

| 能力 | 当前实现边界 |
|---|---|
| `legion_discover` | 当前 Agent 可见工具、用户已配置原生市场、公开 GitHub；失败、未配置和空结果分开 |
| `legion_source` | 固定 commit 读取真实目录／文件、README、依赖和许可证，保留分页／截断／限流等诊断 |
| `legion_bundle` | 包装作者已适配的文件，生成 patch／manifest／locale／icon／provenance，通过原生 `write` 写工作区；同会话／实例／生命周期复用成功的完整 commit 来源事实，错误重取，保留原时间与 hash；每次重新核当前输入、目录和写权限；不安装、不执行输入代码、不改授许可 |
| 原生安装与开关 | 返回官方 `install_bundle` 参数，初始禁用；整包安装、子插件分别启停，不另造运行器 |
| `legion_call` | 明确执行一个本机工具，桥接实现不发 HTTP 或消息；首回执是 pending 子调用观察，不是外层成功 |
| `legion_message` | DSH 看到 Host 外层最终结果后，下一次明确决定发送；有独立操作键及回执，不自动唤醒终态任务 |
| 原有协作工具／命令 | 提交、列表、状态、消息、恢复、取消、下载保留；状态与投递不冒充任务实际消费 |

两步调用不能写成同一个 `run_code` 内“执行＋成功消息”；这是使用协议，不是运行时拦截任意程序的承诺。只有子调用和全部祖先成功，才可确认原生成功。官方 `tools/result` 到根后只记终态元数据，不存子／父正文、不回改首回执、不发送。

同键同参数只恢复元数据，不重做副作用、不回放旧正文；目标能力卸载后也可恢复，但 Legion Bridge、原会话／状态与授权必须还在。v1 无祖先证据不能确认原生成功；**v1 历史投递 ACK 已恢复为独立的只读事实**：有效 `received`／`rejected`／`unconfirmed` 保留，缺失、不可读或畸形记录保持 `unconfirmed`，不重发、不改盘，也不代表模型已消费。

本地实现转交图片、原生上下文和结束回合；跨任务分享仅限经限长、脱敏处理的文本／结构化数据，不传媒体二进制。普通长文本不再仅因长度或外观像 base64 就被删掉，仍受原预算约束。源码里的转交行为、官方 Runtime 隔离证据与作者真正看到结果分开验。

## 当前最大缺口：修好的包还没在真实 Host 安装运行

- **作者修复已发生且有独立运行证据。** 缺 `tools` 注入和 tokens 输出中含非 JSON 值的旧反例已恢复；不是只把反馈排进队列，也不是主线程在 probe 里补代码。官方开发参考仍按需提供，不替作者决定适配业务。
- **最新生成包已读回，但没有安装。** 17 文件包中的运行源码与已执行版本相同；在官方 Loader 的隔离检查中用解析别名连接已有依赖，没有验证真实安装产生的布局。包装与执行证据并列，不把 `execution_verified:false` 改成假成功。
- **来源重试已修磁盘代码，旧 Host 是否加载仍未知。** 当前实现只在同会话、同插件生命周期复用成功固定来源观察；保留原时间、hash 和截断，错误重取，每次走当前写权限。最后保存的原生包装回执没有新 `source_retrieval` 字段，不能用磁盘哈希代替 Host 加载证明。
- **“允许一次”已用于一次原生 `plugin_manager list_bundles` 查询。** 当时连接器 0.2.0 已安装／启用，Marked 包未安装；第二次查询没有授权。该许可不包括安装、启用、重启、永久权限或发布。下一步如安装，应另获仅限 `install_bundle`、初始 `enabled:false` 的具体授权，保留原生审批；不能改走私有 RPC 绕过。

## 冻结的三条发布路线

1. **官方固定 Git 手动安装**：需真实公开、已审阅的完整提交 SHA，不要求先发布 npm；本插件公开 Git 安装未验。
2. **官方 Discover 自托管 Git 索引**：用户自行添加；索引读取与安装分别验，不冒充官方中央审核收录。
3. **1024Store 目录投稿**：单 JSON 新增；无 npm 可 browse-only。固定商店源码提供的按钮为 npm-only，与原生管理器支持 Git 不矛盾。

当前 Git remote 为空；公开仓库／提交、固定 Git 安装、自托管索引、目录 PR／合并／线上收录和 npm 发布均未完成。许可声明不代替权利／发布权限／外发授权，独立新写和复用内容的分发权仍须确认。详见 [MARKET](MARKET.md)。本地检查、打包和功能分支 commit 可继续；不 push、不投稿、不公开发布，不自行安装／启用／重启 Host。

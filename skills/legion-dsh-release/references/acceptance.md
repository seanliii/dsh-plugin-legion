# 验收：回到原目标，把原旅程走完

本文件保存用户明确要求记住的测试与交付偏好。它是执行者的工作方法，不是加在军团上方的质量门或新测试 runner。按本次实际目标选相关旅程，不把历史题目和测试数量固定成必跑清单。

## 1. 完成指的是用户拿到结果

- 开始和结束都核用户原目标、原 Todo 与当前完成账本。全部实质已授权工作及其验证做完，才可说该范围完成；报告、构建、绿测、截图生成或一个子任务结束不能代替总目标。
- 原请求仍有可做缺口就推进：真实体验发现问题 → 修复根因 → 重放原旅程 → 检查用户能否拿到结果。监督者提供的截图／意见要如实记作人工反馈，不能包装成完全自主纠错。
- 一项外部审核、表单或认证等待只阻塞依赖它的动作；并行完成其他可做项。达到预算、安全或取消边界、用户接管、真实阻塞时停止相关操作，留下事实和恢复点，不无限等待或保证永远继续。
- 证据绑定本次版本／hash、环境、入口、输入与实际结果。相同条件下有效证据可复用；修改了相关内容需重放，不把旧版本测试搬来算新版本通过。

分开报告下列事实，未运行用 `not_verified`，真实失败用 `failed`，不适用说明理由；不要用总绿色状态吞掉差异：

| 观察到了什么 | 不能替代什么 |
|---|---|
| 源码存在、仓库登记、函数可发现 | 适配完成、依赖就绪、真实工具调用 |
| 包 hash／安装文件一致、构建或回归通过 | 用户体验、模型任务、全部成员可用 |
| 配置已保存、成员列表可读 | 模型已授权且成功执行 |
| 一家或一个工具真实成功 | 所有 harness／tool／media／device 已验证或普遍领先 |
| 消息已收到、任务 `done` | 模型实际采用消息、正式成果可用 |
| 网站可打开、HTTPS 成功 | 流式任务、鉴权、保存、恢复与云端设备可用 |
| 窄浏览器视口、网页支付模拟 | 真手机操作或真实付款验收 |

## 2. 测试隔离和用户机器

- 测试在专用子进程／会话内隔离 `HOME`、`MEYO_LEGION_DIR`、`LEGION_HOME_DIR`、`TMPDIR`，使用独立 DSH profile、实例和虚拟环境，不改用户 Shell 的全局 HOME。
- 启动器可能再次解析实例路径，读回实际生效目录，不能只设环境变量就假定隔离。测试不碰用户真实 `.meyo`／`.legion`、浏览器配置、原生会话或公司凭据，也不从旧环境偷带依赖。
- Python 环境不使用 `--system-site-packages`、全局 pip 或旧 editable 安装。重安装按当前平台已有全局 lock 串行；安装失败先读原回执，不反复重装，不另写 installer／测试调度器。
- 模型费用、联网、设备和第三方账号按授权范围实跑。只保存配置或不获准调用时，相关模型／成员状态保持 `not_verified`；不能为了补绿灯偷偷调用另一账号或模型。
- 重活前观察负载、内存／swap 和异常进程；负载高先暂停叠加任务、缩小并发并诊断。只回收确认属于本次测试的进程与临时数据，绝不乱杀用户有窗口的应用或关闭其工作现场。
- 生命周期的取消请求、停止等待与远端任务实际停止分别核验。未知结果先按原 requestId／任务引用读取，不换编号重放未知副作用。

## 3. DSH 原生旅程

按实际 UI 操作，不用 curl、DOM 文本、构建结果或截图文件存在替代点击与肉眼检查。

### 新安装与原生入口

1. 从冻结的 Git 来源或官方 Discover 进行本次获授权的新装，确认完整 commit、原生警告、依赖构建状态及安装结果。
2. 对照原 TGZ 的真实文件集，逐文件核安装后的内容；`N/N` 以该包为准。匿名获取发行附件后核大小和 hash；核心 TAR 用可信 `package_core.py` 校验与解包，方法见[发布指南](publication.md)。
3. 在 DSH 原生插件页明确启用，打开军团侧栏并选择当前工作会话。按当前版本检查成员、能力发现、添加能力、任务、配置等页面；无核心时的发现能力不能被“未连接”误挡住。
4. 区分“读取来源／准备可编辑任务”和“实际安装／委托”。查看完整安装回执与真实文件，不把等待脚本文案匹配错或一次超时直接判断为产品失败。

### 保存、刷新和重启

1. 在原生配置界面保存地址和凭据引用，查看保存后读回值，再刷新成员。页面仍显示旧错误时，确认是否需要刷新，不能把表单值当成服务已连接。
2. 刷新页面、重新打开相关页面，检查已保存值、bundle／子插件开关和任务归属。
3. 先等本次专用实例的活任务完成；若需取消，按授权请求并核实终态，再正常停启 DSH Host 与核心。读回同一实例、身份、配置和已有状态，不强杀活任务或重新初始化来伪造恢复。
4. 有原任务时核原会话、工程、断点与正式成果仍在；本次没有任务或新成果，就只报告配置／服务恢复，不说任务续跑或成果下载已通过。

### 模型任务、续作与正式成果

- 获准模型实跑时，从原生入口提交用户原需求，观察实际进度、错误和第一段有用结果，而非改成容易通过的合成题。成员以真实选用者记账，不把接力成功算原成员健康。
- 续作保留原任务引用、工程与合法身份，例如沿 `previous_task_ref` 接回原任务；核实际后续行为，不靠模型口头说“记得”。
- 若声明世界研究、源码互学或经验采用有效，查看本次实际来源、读取、召回及后续行为。实现文件存在和消息 ACK 都不能代替这些证据。
- 从本单正式成果记录执行 `legion_download`／原会话的 `/legion download`；核落盘文件的大小与 SHA-256 对应服务声明，再实际打开**下载后的文件**。文件在 DSH Host，不等于浏览器已下载到用户电脑；按真实交付位置说明如何取得。
- 以用户身份点击核心操作、编辑或保存、刷新再读取；反馈修改后重新下载，核新旧成果、hash 和行为差异。互动网页检查实际渲染和交互，不拿开发目录里的另一份作品替代正式下载物。
- 发现问题修复后回到原路径重放。未跑的成员、媒体或设备单独保留 `not_verified`；不要把局部窄链路升级为所有能力验收。

公网服务还须从外部浏览器做 HTTPS、鉴权、SSE、下载和持久恢复，按[部署指南](deployment.md)执行；本机连接成功不能代替。

## 4. 截图和录屏是证据，不是成品替身

- 仅捕获当前相关应用内容，先确认画面边界。不要录整个桌面、无关邮箱、账号资料、令牌、密钥或其他会话；保存凭据时也不能把秘密拍入画面。
- 截图生成后**逐张查看**，从用户能否看懂、找到入口、完成动作、看清反馈与拿到成果出发检查。不能只看文件名、像素尺寸或自动断言。
- 录屏必须来自真实应用操作，不用旧截图拼幻灯冒充。重录标明“重放”，不假装首次执行；裁剪、剪辑、倍速和等待压缩注明，保留动作与结果的因果关系。
- 支持 CDP 录屏的浏览器可使用当前工具文档提供的 `Page.startScreencast`、`Page.screencastFrame` 和 `Page.screencastFrameAck`。先做一次小探针，确认返回真实图像帧与时间戳；不要打印 base64。若工具的异步上下文只在单次调用内有效，采集循环与操作须在**同一次有界调用**中并行完成，最后停止并等待采集结束；不能把后台 Promise 留到下一次工具调用。
- 稀疏帧流按记录时间戳编码，静止画面仍保留实际停留时长，不能用帧数量直接冒充秒数。可附慢放加说明版，但同时保留原速版；说明条放在原画面之外，不遮错误、状态或关键控件。只采当前专用标签页，不录登录 URL、凭据值或其他窗口。
- 视频交付前用 `ffprobe` 核流、时长、尺寸与编码，再完整解码检查。下列模板只读取视频，不生成新 runner：

```sh
ffprobe -v error \
  -show_entries 'format=duration,size:stream=index,codec_type,codec_name,width,height,avg_frame_rate,duration' \
  -of json "$VIDEO"
ffmpeg -nostdin -v error -xerror -i "$VIDEO" \
  -map '0:v?' -map '0:a?' -f null -
```

- 读完退出码和诊断，再回看录屏，肉眼查看首／中／尾、关键点击、保存／刷新／重启和成果展示帧。确认不是黑屏、旧画面、错误窗口、不可读文字或遗漏核心操作；完整解码通过不等于体验通过。
- 有问题就修复、重新录制并再次检查。公开前审查实际媒体和元数据，必要裁剪不隐藏失败或制造假成功；原始私有证据不随技能或发行包公开。

## 5. 浏览器与表单恢复

先确认当次工具策略与用户指定的浏览器／标签页。技术 stale 时读该工具文档，重新列出并选择**同一个 tab**，或按文档 reset／恢复连接后重新观察页面。一次错误不应触发多个新浏览器或重复安装／提交。

提交类动作先核原结果，避免重复副作用。GitHub 工具返回交互表单不算保存；在授权和策略允许时可用原生 GitHub 界面完成编辑，保存后 readback。只引导用户操作其真实可见的控件，不编造“不可见 Submit”；表单失踪不是永久等待规则。

用户接管时立即停止自动界面操作；身份认证、验证码或真正需要用户决定的事项交还本人，不另开浏览器抢操作。技术恢复仍受阻时记录具体状态与恢复点，继续不依赖该界面的已授权工作。

外部搜索与源码读取失败按真实来源分别记录。GitHub 搜索成功不代表源码接口仍有额度；遇到 403／429，保留可用的限流、重置时间和正文可见性，等待允许的时间再重试，不用换账号／代理伪造恢复。视频中保留该失败；此前另一版本或另一时点的成功不覆盖这次失败。
